# Changelog

## 2026-10-31 build

- Many clips, one clock (`src/vedit/project_media.py`): a project takes 1 to 30 videos and photos. One video stays its original file with no re-encode. Anything else becomes `project-source.mp4` through the new `project_source` op, one step per item then a stream-copy join: the first item's shape capped at 1920, 30 fps, 48 kHz stereo, silence where an item has none, and a blurred copy behind a different shape. Photos hold for 3 s (`photo_seconds`), with EXIF orientation and tiled HEIC handled; HDR clips are tone mapped. `job.source.clips` lists `{name, kind, start, end}`, clip boundaries join the scene cuts, and the local planner gives each clip a fair share. Limits rise to 4 GB per file and 2 hours per project.
- `POST /api/campaigns/{id}/assets` registers uploaded audio and images after real probing and keeps a copy in the job, with beat times for music. `GET /api/campaigns/{id}/filmstrip` and `/waveform` serve a JPEG sprite and peaks made when the plan finishes; a failure there is a warning. `/api/upload` reports the file's `kind` and refuses non-media that does not claim to be video.

- `briefcut` command: with no arguments it opens Studio (first free port from 8765, or the Studio already running), storing projects beside the Mac app's. With arguments it is `vedit`. `scripts/install.sh` installs uv, FFmpeg, and the command on macOS and Debian or Ubuntu, says what it will do first, asks before each step, and has `--dry-run`.
- First-run setup in Studio (`GET /api/setup`, `src/vedit/onboarding.py`, built on `vedit.doctor`): FFmpeg with the filters Studio needs, the speech model, and Meta access, with exact commands for this machine and **Check again**. `POST /api/setup/model` downloads `ggml-base.en.bin` in the background with progress and resume, and accepts it only when size and SHA-256 match what Hugging Face publishes. `vedit setup` is the same report in a terminal.
- Settings (`GET/POST /api/settings`, `src/vedit/settings.py`, `~/.vedit/config.json` with mode 0600): Meta key (macOS Keychain when available, write-only either way), Meta on or off, contributor mode with a plain explanation, default budget and caption language, project folder. `meta.capabilities()` and the adapter read these; the environment still wins. **Test connection** runs the free `vedit meta check`.
- Project library (`src/vedit/projects.py`, `src/vedit/studio/product.py`): thumbnails, title, date, duration, status, and size on disk; open, rename, duplicate, delete (`DELETE /api/campaigns/{id}`), total storage, and "clean up renders of old versions". Removal stays inside the workspace, never follows a link, keeps an inbox copy that anything else mentions, and never touches the latest verified version.
- Reliability: interrupted jobs are labelled in the library and announced on opening; autosave state shows in the top bar; "Copy diagnostics" gathers versions, doctor results, and the last error with no home folder paths, keys, or transcript text. A job deleted while queued no longer stops the worker. Retry after Studio is killed mid-render now works: the partial file the killed encode left made the compiler fail with a message blaming the source, so a retry starts an unverified revision's folder clean.
- `whisper-cli` is found in one place (`media.find_whisper_cli`), including Homebrew's folder and `~/.local/bin` when PATH does not list them. Before, Studio could report captions ready and then fail the render.
- FFmpeg 6.1, Ubuntu 24.04's version: dense graphs use `-filter_complex_script` below FFmpeg 7, and cutouts use ordinary `scale` expressions; FFmpeg 9 was verified, but FFmpeg 6.1 remains unverified. The cutout background still now keeps its shape on every version; the old expression stretched it to the frame.
- Mac app: the DMG now carries its own CPython 3.13 and PyYAML, because a GUI launch cannot see a Python under `~/.local`; bytecode no longer goes into the bundle, which broke its signature. FFmpeg stays external and the first-run panel says so. Not notarized.
- Linux: doctor and setup give apt commands, never Homebrew ones, and the whisper.cpp build steps, since no package exists. `GET /api/capabilities` reports `host` (`platform`, `hardware_encoder`, `keychain`, `narration_voice`, `native_app`). Studio says "this computer", not "your Mac".
- `docs/PRIVACY.md`: what stays local, what goes to Meta and when, contributor mode, and no telemetry.

- `vedit mcp`: Briefcut as an MCP server for coding agents (`src/vedit/mcp_server.py`, optional extra `mcp`): import a clip, create a story, wait, render, revise, read receipts, resolve artifact paths. A director's note now runs through the worker with its own "noting" stage, so the revise request returns immediately.
- Receipts: "auto: subject stays in frame (SAM 3.1)" grades the real SAM track against the reframed crop (`subject_in_frame_check` in `src/vedit/lint.py`). Spatial effects now float over a blurred, darkened copy of the footage instead of a slate card. The director prompt treats a length named in the brief as a ceiling, so a shorter complete cut is not penalised. Deterministic lint re-runs after director or note patches.

- Demo clip: `examples/demo/workshop.mp4` is now stylised computer-generated footage of an oak bowl on a workbench, five 8 s scenes (finished bowl, raw oak blank, turning with gouge and shavings, sanding, oil finish) with film grain and a vignette, no baked-in text, narrated by the macOS `say` voice (Samantha, falling back to the default). `scripts/make_demo.py` builds it; `tests/test_make_demo.py` covers it. It is not real footage.
- Captions: `polish_cues` in `src/vedit/captions.py` collapses doubled words (also across cue edges), merges fragments into sentence-level cues, capitalises each cue, and `wrap_cue_text` breaks long cues into two balanced lines of at most 42 characters. Applied to local Whisper and Meta Voice Transcribe cues.
- Story planning (`src/vedit/story.py`): transcript sentences are clamped to measured speech; every cut is snapped to a sentence boundary (`snap_to_sentences`, also applied to Muse Spark plans in `CampaignManager._plan`); process briefs spread moments across scenes with an equal-span fallback; titles, labels, hashtags, and post copy come from the brief and the spoken sentences; scene-cut detection keeps sparse weaker cuts when no strong change is found. The Muse Spark prompt lists sentence boundaries as preferred cut points.
- Receipts and the self-correcting loop: `src/vedit/lint.py` grades every verified version (sentence boundaries, duration vs target, bounds and order, caption coverage) and proposes structured patches; `apply_patches` is pure and reports skipped patches instead of raising. `meta.review_cut` now returns structured `checks` and `patches` beside the prose notes; `meta.patch_plan` turns a typed director's note into patches with a text-only call. `POST /api/campaigns/{id}/revise` with `mode` `director`, `auto`, or `note` renders version N+1 while the previous verified version stays downloadable; the deterministic lint re-runs after model patches. Jobs carry `versions`; results carry `checks`, `passed`, `total`, and `patches`. `scripts/demo_run.py --revise director|auto|note` records a revision. Studio shows version tabs with pass counts, "The receipts" with jump-to-time, "Apply director's fixes", "Apply automatic fixes", a director's note box, and "What changed in vN".
- Brief-driven edits: `src/vedit/brief_ops.py` maps phrases in the brief to ops (trim the pauses → `cut_silence`; title card or `title "…"` → timed title; fade in/out; denoise; no loudnorm; `hook:` and `cta:` overlays). Applied and ignored requests appear as `decisions` and `ignored_edits` on the plan and as the receipts check "auto: requested edits applied". Studio adds the "Product story, edited" chip.
- Whisper models live in the shared `~/.vedit/models/` (`VEDIT_MODELS_DIR`), found by `scripts/studio.sh`, `scripts/demo_run.py`, `vedit doctor`, and the captions module, with the checkout's `.vedit-models/` as the fallback.
- Tests run with pytest-xdist (`uv run pytest -n auto`), in CI too.
- Evidence: `docs/evidence/20261031T070719Z.json` and `latest.md` record the live Meta loop on the demo clip (Spark contributor plan on sentence boundaries, SAM 3.1 tracking of "the wooden bowl", Meta captions, Muse Image cover, Director's notes with checks and patches, `--revise director` to a verified version 2; 13/14 then 12/13 checks; $0.3131 reserved of $0.50). `20261031T083945Z.json` records the note-driven revision live (15/15 with the SAM receipt, then 13/15). `20261031T071627Z.json` is the local baseline on the same clip (plan 1.5 s, render 18.2 s, 5/5 checks).
